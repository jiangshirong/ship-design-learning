# 维护与重建

## 运行和导出

Godot引擎及Windows导出模板为开发工具，不捆绑进仓库。本机工具在 `%LOCALAPPDATA%/ShipLearningTools/Godot/4.7.2/`，Windows release模板已放入Godot标准导出模板目录。其他电脑自行安装同版本引擎与模板。`export_presets.cfg`使用标准模板，不再依赖项目内的104 MiB模板文件。

可运行 `runtime/godot.exe --headless --editor --import --quit --path .` 重建导入缓存。正常学习仍双击根目录启动脚本。

## 内容维护

- `content/courses.json`及相关JSON：当前原作业讲解。
- `modules/review/content/reading.json`：课程题目62题。
- `modules/review/content/exam12/reading.json`：考前66题及6组识图。
- `modules/review/content/exams/reading.json`：考试真题10题。
- `tools/focused_new_answers.py`：12p/13a答案的维护源，`reasoned_answers_data.py`会使用它覆盖兼容旧稿。
- `tools/exam13.py`：13a来源导入、去重及归类。
- `tools/merge_duplicate_questions.py`：确认重复题的合并规则。
- `tools/thursday_exam.py`：独立真题题库构建，不放回考前题库。
- `tools/calculation_notation.py`：四道计算题原题符号、完整演算、演示条件。

原始课件位于工程上一级而不在本项目内；重新从DOCX导入需自行提供。已提交的运行JSON足以离线学习。不要执行历史归档内的单次修改脚本。

## 公式

已编译MathJax SVG随项目保留，不降低显示精度。仅修改公式时才需要Node：在 `tools/latex` 执行 `npm ci`，然后分别运行 `node tools/latex/build.cjs` 与 `node modules/review/tools/latex/build.cjs`。依赖版本已锁定。本机另有开发依赖缓存 `%LOCALAPPDATA%/ShipLearningTools/node_modules`；它不属于仓库。两份 `qa/formula-values.json` 是编译用基准，已保留。

现有GDScript测试使用隔离存档，输入只投递给应用。可从启动脚本传入 `-- --qa --exam-bank-routing` 检查三个入口；或 `-- --qa --export-smoke` 检查实际海面和精细模型。旧测试需要的历史截图或快照在归档中，运行前按需恢复，不能用旧快照覆盖当前题库。

## 历史资料

`archives/history-manifest.json`记录历史文件与SHA-256，同内容重复文件只存一次。用支持tar.xz的软件解压；恢复到单独目录查看，勿覆盖当前工程。旧截图大多可再生成，保留近期20张代表画面，其余临时截图不再存储。`legacy-notes-and-oneoff-tools.tar.xz`含旧说明及已停用单次改稿脚本。
